# VOSC Activity-1: Tic-Tac-Toe Game

A lightweight, responsive Tic-Tac-Toe game built with pure HTML, CSS, and vanilla JavaScript for **VOSC Activity 1**.

## Features

- Clean dark-mode responsive UI
- Two-player turn-based gameplay (Player X and Player O)
- Dynamic win and draw detection
- Reset game functionality
