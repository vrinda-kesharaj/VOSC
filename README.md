# VOSC Activity-1: Tic-Tac-Toe Game

A lightweight, responsive Tic-Tac-Toe game built with HTML, CSS, and vanilla JavaScript.

## Features
- Turn-based 2-player mode (Player X and Player O)
- Win and draw detection
- Reset game functionality

## Project Structure
- `index.html` - Game board and layout
- `style.css` - Styling and dark theme
- `script.js` - Game mechanics and logic
- `README.md` - Documentation

## How to Play
1. Open `index.html` in any web browser.
2. Players take turns clicking cells to place X or O.
3. Align 3 in a row, column, or diagonal to win.
